# M365 Copilot for Leaders

A mobile-first course in effective M365 Copilot use for managers and heads of
department. Daily micro-lessons on the phone, a weekly lab in the M365 Copilot
app, Outlook, Teams, Word and SharePoint, and a capstone in which each learner
designs a project memory ("Third Brain") for their own team.

All scenarios, people and data are fictional. The course uses only M365 Copilot.
Labs need no API keys, admin rights or licensed simulation software.

**App:** https://betro-vestas.github.io/applied_ai_course/
(on iPhone: open in Safari, then Share, then *Add to Home Screen*)

- Plan: [`docs/PLAN.md`](docs/PLAN.md), with the full design in [`docs/PLAN v0.3.md`](<docs/PLAN v0.3.md>)
- Rules for contributors and AI agents: [`.github/copilot-instructions.md`](.github/copilot-instructions.md)
- Course content: [`content/`](content) (Markdown + YAML)
- Lab files for the work laptop: [`labs-sandbox/`](labs-sandbox), generated by [`scripts/generate_project_pack.py`](scripts/generate_project_pack.py)
- Upstream reference content: [`reference/`](reference)

## Development

```sh
npm install
npm run dev      # local dev server
npm run build    # type-check and build to dist/
```

Pushes to `main` run the content guard, then build and deploy to GitHub Pages.
The content guard reads a newline-separated list of banned terms from the
`BANNED_TERMS` repository secret.
