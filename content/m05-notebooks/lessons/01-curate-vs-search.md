### Two ways to ground Copilot

| | Search everything (Work mode, Premium) | Curated set (Notebook) |
|---|---|---|
| **Scope** | Everything you can access | Only the sources you added |
| **Strength** | Finds things you didn't know existed | Consistent, focused answers |
| **Weakness** | Ranking noise, misses, and other projects leak in | Only as complete as your curation |
| **Best for** | "Is there anything about X?" | "Answer from *this* project's record" |

Module 3 showed the weakness of searching everything: the right email may not
rank near the top. A **curated** source set fixes that for the documents that
matter most, because Copilot grounds its answers only on what you have added.

### Microsoft 365 Copilot Notebooks

A **Copilot Notebook** is a workspace that brings together a set of references
(files, pages, emails and, with Premium, meetings and chats). You chat with
Copilot grounded on those references, and you can keep notes and pages alongside
them.

| | Copilot Chat | Premium |
|---|---|---|
| Create notebooks | Yes | Yes |
| Sources per notebook | Up to 50 | Up to 300 |
| Word, Excel, PowerPoint, PDF, OneNote, Loop, email threads | Yes | Yes |
| Teams chats, meeting transcripts and recaps, URLs | No | Yes |
| Suggested references | No | Yes |

Limits like these change. Check them against current Microsoft documentation
before you rely on them in a plan.

You can add **a SharePoint site, library or folder** as a reference. Copilot
then uses the supported files in it that you can access. For a critical file,
add it directly so you know it is included.

### Why this helps Chat-only users

Notebooks are the best grounded experience available without Premium. A Coral
Ridge notebook with the key files gives a Chat-only user most of the retrieval
benefit, as long as the right files are in it.
