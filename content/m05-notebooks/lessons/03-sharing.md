### Shared memory

Notebooks can be shared with colleagues, which turns a personal memory aid into
a **team** one. Two rules from Module 1 still apply:

- **Permissions still apply.** A colleague only gets answers from references
  they can access. If you added an email thread from your own mailbox, they may
  not be able to see it.
- **Licences still apply.** A Chat-only colleague gets the Chat experience: fewer
  sources, and no meeting or Teams chat references.

### Practical consequence

For shared project memory, **put the key evidence in a shared location**, such
as the project SharePoint folder or Teams channel files, not in personal mail.
Then everyone with access to the project works from the same memory.

This is a habit change. "Save the confirmation email to the project folder" can
feel like admin. In a Third Brain, it is what makes the answer findable for the
whole team.

### Pages: turning answers into records

When Copilot gives you a good answer that you have verified, for example the
HP-2 witnessing position, **save it as a page** in the notebook, with its
sources. Next time, you read a verified record rather than re-asking. Over time,
the notebook builds a set of verified facts.
