- **Where:** Microsoft 365 Copilot app, Notebooks.
- **Data:** Coral Ridge training folder (synthetic files listed in the project pack, `04-lab-files.md`).
- **Goal:** build a Coral Ridge notebook, rerun the Module 3 lab questions, and compare the answers.

### Setup (5 min)

Create a notebook called "Coral Ridge: project memory (training)".

### Part A: curate (10 min)

Add these references: CR-00, CR-01, CR-02, CR-09, CR-11, CR-12, CR-13, CR-14,
CR-15, CR-16 and CR-17. Or add the whole training folder, then compare in Part D.

Create a **read-me page** that holds the standing brief from lesson 2.

### Part B: rerun the Module 3 questions (15 min)

Start a notebook chat by pasting the standing brief. Then ask the five Module 3
lab questions **as plain questions**, with no follow-ups. For each one, record the
answer type: Complete, Partial or Wrong.

### Part C: save verified answers (5 min)

For two answers that you have verified by opening the sources, save them as a
**page** called "Verified facts", with the sources listed.

### Part D: folder vs files (5 min, optional)

Make a second notebook that references the **whole training folder** instead of
selected files. Ask question 1 again. Does the answer change, and does it cite
different files?

### Reflect

1. How many of the five answers were Complete first time, compared with your
   Module 3 Part A results?
2. Which instruction in the standing brief did the most work?
3. What did leaving out CR-03 to CR-08 cost you, if anything?

### If something isn't available

- **Notebooks not visible:** your organisation may not have enabled them yet.
  Use a single chat with the same files attached and the same standing brief.
- **Only Chat, no Premium:** Teams chats and meeting transcripts cannot be added.
  Use the exported documents in the training folder, which the lab already
  provides as files.

### Answer key (check after you finish)

With the brief and the curated set, you should expect most answers to be
Complete first time. The usual remaining weakness is question 4, which needs a
date worked out from other documents. If that happens, follow up once with
"calculate the due date from the test date and the commitment; show your
working", then check the working against the sources.
