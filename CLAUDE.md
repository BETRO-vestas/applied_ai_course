# Repository rules

This repo is a personal learning course on applied AI and agentic workflows for
a grid connection team working in Australia's NEM. See `docs/PLAN.md`.

## Confidentiality (hard rules)

- Never name the author's employer, its products, customers or real projects,
  or any individual at a TNSP, AEMO or customer.
- Never include internal documents, real network models, real study results,
  real correspondence or real GPS values. Use the fictional project pack in
  `content/project-pack/` and synthetic data only.
- Refer to network businesses generically ("the TNSP"). Public bodies and public
  documents (AEMO, AEMC, the NER, AEMO guidelines) may be named and cited.
- If a request would add identifying or real data, stop and ask.

## Content conventions

- Cite NER clauses and AEMO guidelines by their public reference, and remind the
  learner to check them against the current version.
- Lessons are decision-first: each ends with a "what would you do?" prompt.
- Labs must run with VS Code + GitHub Copilot alone (Chat, agent mode, custom
  instructions, prompt files, and the M365/SharePoint and Atlassian MCP tools)
  with no API keys, admin rights or licensed simulation software.
